# E-Commerce Analytics on MongoDB with a Query Optimization Advisor

## Project Overview
This project uses MongoDB to store and analyse large-scale e-commerce data. It demonstrates database operations, aggregation pipelines, indexing, and query performance analysis using MongoDB Compass.

## Database Information
- **Database:** ECommerceAnalytics
- **Database:** MongoDB
- **Interface:** MongoDB Compass
- **Orders:** 100,002 documents

## Collections
1. customers
2. products
3. orders
4. reviews
5. inventory_logs
6. query_logs
7. optimization_recommendations

## Key Features
- E-commerce sales analysis
- Payment method revenue analysis
- Top 10 products analysis
- City-wise revenue analysis
- Single-field and compound indexing
- Query performance analysis using Explain Plan
- Query optimization recommendation records

## Technologies Used
- MongoDB
- MongoDB Compass
- JSON / BSON
- MongoDB Aggregation Framework

## Documentation
See `Aggregation_and_Indexing_Documentation.md` for aggregation queries, index details, Explain Plan comparison, and optimization recommendations.

## Project Objective
To demonstrate how MongoDB can efficiently store, retrieve, and analyse large volumes of e-commerce data using NoSQL database concepts.

## Conclusion
The project demonstrates practical implementation of MongoDB CRUD operations, aggregation pipelines, indexing, and query performance analysis on a synthetic e-commerce dataset.
